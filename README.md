I build the part of a product users never see but always depend on: **APIs, data, and the workflows between services**. I care about systems that stay correct under retries, concurrency and failure, and about code a team can still change a year later. I use Claude Code daily to move faster without lowering the bar.

## What I build

| | |
|---|---|
| **API & architecture** | REST and gRPC/Protobuf services · Clean Architecture, CQRS, Hexagonal (ports and adapters) · API gateway with Spring Cloud Gateway |
| **Data** | PostgreSQL (TypeORM, Row Level Security), MySQL, MongoDB, Redis · schemas designed around access patterns and integrity |
| **Async & event-driven** | Kafka sagas · BullMQ/Redis queues · Outbox pattern for reliable delivery · idempotent payment webhooks |
| **Real-time** | WebSocket and Cloudflare Durable Objects · server-authoritative state machines for rooms of 6–30 players |
| **Security** | JWT (incl. RS256) · two auth flows side by side (admin login, Zalo MiniApp OAuth) · RBAC with CASL · secrets protected at the database layer |
| **AI in the backend** | Provider-agnostic LLM layer (OpenAI, Gemini, Groq behind one port) turning chat into structured orders |
| **Delivery** | Docker · Git workflows and code review · AWS (EC2, S3) |
